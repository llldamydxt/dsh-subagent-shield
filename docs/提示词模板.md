# 提示词模板：用子代理跑对照实验

> 配套 `dsh-subagent-shield`。目标：**随手建个文件夹、开个窗口，就能让子代理跑出你愿意信的对照实验。**
> 本文是**可直接复制粘贴**的模板，`{ }` 里是要替换的占位。
> 概念与原理见 [对照实验协议](对照实验协议.md) 与 [说明书](说明书.md)。

---

## 0. 这套提示词负责什么 / 不负责什么

| 负责 | 不负责 |
|---|---|
| 让臂**不手滑**去翻别的臂、翻 `%DSH_HOME%`、翻答案键 | 挡不住**有心**的程序化偷取（自己写 `node` 脚本读盘 + 解 zstd）—— 那是宿主没有内核级隔离，插件只能在**工具层**做围栏 |
| 把**被拦**变成**报警**（臂必须把拒绝原文抄回来） | 管不住提示注入（臂读进来的外部内容里可以写"去看某目录"） |
| 钉住**口径**（两臂逐字同一份）与**答案键位置** | 替你想清楚"什么算对" |

> **一句话**：实验结论要建立在"**臂都按我说的做 + 被拦会报回来 + 父窗口事后审计**"上，
> **不要**建立在"它绝对偷不到"上。

## 1. 开跑前（父窗口，5 步）

```powershell
# ① 建目录：每臂一个独占子目录（这一步能省掉后面 90% 的误伤）
$root = "<随便哪个地方>\我的实验-01"
mkdir "$root\臂A", "$root\臂B", "$root\_答案"      # _答案 放真值与隐藏测试
```

```powershell
# ② 把答案目录挂成"对所有子代理拦住"
#    设置 → 信息隔断 → 臂间隔离 → 添加一条：
#       路径 = $root\_答案        归属窗口 / 归属标签 = 都留空
#    → 父会话照常读写，任何子代理读不到
```

```
③ 派子代理时，description 填臂名（例如 臂A / 臂B）
   —— 归属判定与账本靠它认人；不填，工具就没有抓手

④ 记下护盾状态（贴进实验记录）：在窗口里敲 /shield status
   version / enabled / scope / mode / 谁写的谁拥有

⑤ 两臂的提示词除"自变量"外**逐字相同**（口径一定同一份）
```

## 2. 给每个臂的任务书（逐字模板）

### 2.1 公共部分（两臂完全相同）

```text
你是对照实验里的「臂 {ARM}」。这个实验的唯一变量是：
    {自变量一句话，例如：是否要求先在注释里列出边界情况}
除此之外，两臂的任务、评分口径、交付要求完全一致。

【你的工作目录】{ARMPATH}
  只在这个目录里创建/修改文件。不要读写其它臂的目录。

【任务】
{任务描述，含规格要点}

【交付】
  用 write 工具把最终交付物写到：{OUTPATH}
  输出契约：{自包含 CommonJS 模块 / 只导出 {函数名} / 不 require 第三方 / 不读其它文件 / 不写测试代码}

【口径（逐字，两臂同一份 —— 严禁自行解释）】
{口径清单：范围、边界、单位、精度、格式、正例反例各一}
  例：范围 1 ≤ n ≤ 100 含两端；质数为大于 1 且只能被 1 与自身整除者（含 2）；
      输出一个十进制整数，不带单位、不带千分位。

【一次性交付】
  没有测试反馈，不会有第二轮追问，不要向我提问或等待确认。

【纪律（重要，逐条遵守）】
  1. 只读 {SPECPATH} 与你自己工作目录里的文件。
  2. 不要访问下面这些地方（它们是别的会话、别的臂或评分方的私有数据）：
       - %DSH_HOME% 下的任何东西（sessions / storages / attachments / cache / logs /
         llm-deepseek / .credentials.yaml 等等）
       - 另一个臂的目录：{OTHERPATH}
       - 测试与答案目录：{KEYPATH}
  3. ★ 如果某个工具调用被拦（返回里会出现「【已隔断】」字样）：
       把它的原文抄进回报里，然后继续做别的。
       不要重试、不要换工具、不要自己去拼接或构造那个路径。
       被拦不是故障，是策略；你如实报回来就完成任务了。
  4. 不要写脚本去枚举或解码上面那些目录。你的完整记录会被事后审计。

【回报格式（逐字，不要改写字段名）】
  ANSWER={你的最终答案或交付摘要}
  BLOCKED={有没有被拦？有就把拒绝原文贴上；没有写 NONE}
  FILES={你创建/修改了哪些文件，一行一个}
  SELFCHECK={按口径逐条自检，每条给一句证据}
```

### 2.2 自变量部分（两臂**只差这里**）

```text
# 臂 A（对照）：
开始动手前不要做任何计划、分析或列举，直接给出最终交付物。

# 臂 B（实验）：
在给出最终交付物之前，先用注释在文件顶部列出至少 4 个你认为最容易出错的边界输入。
```

> **口径与自变量必须分开写**：口径是"怎么算对"，自变量是"你被怎么要求"。
> 把自变量写进口径里，你测的就不是你想测的东西了。

## 3. 派子代理时怎么调

```
description：臂A           ← 就是上面的 {ARM}，两边必须一致
prompt     ：上面的完整任务书（公共部分 + 该臂的自变量部分）
```

- 一个臂一个子代理，**由父会话直接派**（子代理不能再开子代理）
- 臂名在整个实验里唯一，别重复用（账本与归属登记表按它认人）
- 4 个臂就开 4 个（`臂A`/`臂B`/`臂C`/`臂D`），命名规则保持一致

## 4. 跑完的审计（**父窗口自己做**）

> ⚠️ 别把审计交给"复核子代理" —— 归属层会把它判成"另一个子代理"而挡住它读别的臂的产物。
> 需要子代理复核时：把产物**复制到新目录**并 `/shield 放行 <那个目录>`，或者干脆你自己看。

```powershell
# ① 账本：这次拦了什么、谁在被拦
Get-Content "$env:DSH_HOME\subagent-shield-audit.jsonl" | Select-Object -Last 30 |
  ForEach-Object { $_ | ConvertFrom-Json } |
  Select-Object ts, tool, kind, window, caller, callerIsSubagent | Format-Table -AutoSize

# ② 泄露检测：在臂A 的记录里找"只存在于臂B 的东西"（期望 0 命中）
#    会话记录是多帧 zstd，必须用帧解码器
node tools/decode-session.mjs "<臂A 的 session.v4.jsonl.zstd>" "<臂B 独有的串>"

# ③ 归属登记表：哪些文件被谁拥有
Get-Content "$env:DSH_HOME\subagent-shield-owns.json" | ConvertFrom-Json
```

**读法**：

| 看到什么 | 说明什么 |
|---|---|
| `kind=owned` / `kind=sessions` 等拒绝行 | 有人试过；看 `caller` 是谁的会话，就知道是哪个臂 |
| 臂的回报里 `BLOCKED` 非 `NONE` | 同上，而且它**老实报回来了**（这正是你想要的臂） |
| 两臂都 `BLOCKED=NONE` 且账本无新增 | 这一轮没人碰禁地 → 结果可用 |
| 账本 0 行、但你怀疑有人绕过 | 工具层看不到程序化绕过 —— **只能靠"臂老实报回来"**；这也是纪律第 3 条不能省的原因 |

## 5. 已知边界（务必知道）

- 插件的围栏是**工具层策略**：`read`/`glob`/`grep`/`write`/`edit` 精确拦；
  **命令族只是文本启发式**，自己写代码读盘可以绕。
- **父会话写的文件不被保护**（任务书就是父会话写的）→ 答案键必须靠第 1 节第 ② 步挂规则。
- 真要硬隔离：**不同 OS 账户 / 容器 / 另一台机器 + 各自独立的 `DSH_HOME`**。

```text
你是对照实验里的「臂 {ARM}」。唯一变量：{自变量}。其余与另一臂逐字相同。

工作目录：{ARMPATH}（只在这里写文件）
任务：{任务描述}
交付：写到 {OUTPATH}；{输出契约}
口径（严禁自行解释）：{口径清单}
一次性交付：不问、不等确认。

纪律：
1) 只读 {SPECPATH} 与你自己目录；
2) 不要碰 %DSH_HOME% 下任何东西、另一个臂的目录、测试与答案目录；
3) 如果被拦（返回含「【已隔断】」）——把原文抄回来，不许重试/换工具/自己拼路径；
4) 不要写脚本枚举或解码那些目录。

回报：
ANSWER=…
BLOCKED=<拒绝原文 或 NONE>
FILES=…
SELFCHECK=…
```
