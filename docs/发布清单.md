## 2. 推之前：三件事必须确认

### 2.1 包干净

在仓库目录里跑：

```powershell
git status --porcelain          # 只该出现本仓库自己的文件
git ls-files | Select-String -Pattern 'node_modules|\.credentials|audit|rules\.json|state\.json'
# ↑ 这一条必须**没有输出** —— 有输出就说明凭据/账本/规则文件被跟踪了
```

本仓库的 `.gitignore` 已经排除：`node_modules/`、`.credentials.yaml`、`subagent-shield-{rules,state,audit}.*`、`*.bak*`。

### 2.2 没有本机路径

```powershell
Select-String -Path (Get-ChildItem -Recurse -File | % FullName) `
  -Pattern 'C:\\Users\\[^\\]+\\'
# 预期：无输出
```

### 2.3 测试是绿的

```powershell
cd test
node test-matrix.mjs     #  10
node test-shield.mjs     # 138
node test-ui.mjs         #  98
node test-blast.mjs      #  32
node test-browser.mjs    #  22（需要 Edge/Chrome）
# 合计 300，全绿才算能推
```

环境变量（都不设也能自动探测）：`DSH_CHECKOUT` / `DSH_BIN` / `DSH_NODE` / `DSH_HOME` / `DSH_BROWSER`。

## 5. 关于 CI（现在故意不做）

`.github/workflows/` 目前是空的，**这是有意的**：这套测试要跑起来需要

1. 一份**可安装的 DSH**（`@deepseek-ai/dsh` 目前没有公开可装的发布），
2. **Windows**（安装器用 PowerShell / `mklink` / `taskkill`），
3. 一个**浏览器**（`test-browser` 用 CDP 驱动 Edge/Chrome）。

少了第 1 条，GitHub 的 runner 上大部分套件只能跳过 —— 那样交出来的是一盏**永远绿但没测东西**的灯，
比没有 CI 更坏。等 DSH 有公开发布、或本插件改为宿主无关的纯函数测试之后再加。
