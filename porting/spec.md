# 判定语义规格（可整段照搬）

这是 `dsh-subagent-shield` 的核心，**不依赖 DSH**。函数名沿用现有实现，方便对照源码。

建议保持这些函数**纯粹**（不碰 IO、不读全局），IO 留给适配层 —— 这样单测才跑得起来
（DSH 版的 `test/test-matrix.mjs` 就是这么测的：0.2 秒跑 37 项，不启动任何东西）。

---

## 1. `normalizePath(raw) -> string`

把任意写法的路径归一成可比形式。

```
1. 非字符串 / 只有空白          → 返回空串 ''        ← 关键，别返回分隔符
2. 去掉成对的首尾引号（"…" / '…'）
3. 分隔符统一（Windows: / → \）；去掉 \\?\ 前缀
4. 拆段：丢掉空段与 '.'；遇到 '..' 弹出一段
5. 统一大小写（Windows 不敏感；POSIX 宿主请改为保留大小写）
6. 重新拼接
```

> ⚠️ 第 1 条是踩过的坑：空输入若返回 `'\'`，调用方写 `normalizePath(x) || 默认值` 时
> 会因 `'\'` 是 truthy 而走错分支 —— DSH 上真的导致审计文件失去保护。

## 2. `classifyTarget(home, path) -> Target | null`

把目标路径解析成**它属于什么**。

```js
Target = {
  kind: 'sessions' | 'projcache' | 'credentials',
  ws:   string | null,   // 工作区标识（DSH 里是 cwd 的编码目录名）
  sid:  string | null,   // 会话/窗口 id（能定位到就用）
}
```

分类规则（照你宿主的布局改写）：

| kind | 判据 |
|---|---|
| `sessions` | 落在 `<home>/sessions/<ws>/<sid>/…` 之下 |
| `projcache` | 落在投影缓存目录之下（**明文**，常含进行中的草稿 —— 最容易被忽略的一类） |
| `credentials` | 宿主凭据文件（任何路径下命中文件名即算） |
| `null` | 其它（不保护） |

**还需要一个宽松版** `classifyTargetLoose(home, raw)`：允许路径**还不存在**、
带引号、带 `..`、大小写不同 —— 因为工具调用里的路径参数经常是这种形状。

## 3. `isProtected(target, rules) -> boolean`

按规则的优先级决定"这一类目标现在保不保护"：

```
窗口级（windows[sid]）  >  工作区级（workspaces[ws]）  >  目录级（后代并集）  >  defaultPolicy
```

- `defaultPolicy: 'protect'` —— 默认全保护，只放行点名的
- `defaultPolicy: 'allow'` —— 默认不保护，只保护点名的
- 目录级：如果某个工作区**有后代**被点名，则该目录本身也算受保护
  （否则 `glob *` 会从目录层面把清单摸走）

## 4. 归属与臂间隔离

### 4.1 `matchProtectedPath(target, rules) -> Entry | null`

```js
rules.protectedPaths = [ { path, owner?, label? } , … ]
```

命中条件（**必须要求分隔符结尾**，否则 `…\臂A` 会误吃 `…\臂A2`）：

```js
t === p || t.startsWith(p + SEP)
```

返回 `{ path, owner, label }`。

### 4.2 `isOwnerCall(who, entry) -> boolean`

`who = { window, callerId, label }`。**三条判据任一条命中即放行**：

| 判据 | 语义 | 对应跑法 |
|---|---|---|
| `entry.owner` 匹配 `who.window` | 父会话（窗口）是归属者 | 一臂一窗口 |
| `entry.owner` 匹配 `who.callerId` | 调用者**自己**就是归属者 | 子代理自报会话 id |
| `entry.label` 是 `who.label` 的**子串**（都小写、去空白） | 派发时给的标签匹配 | **一个窗口开多个子代理** |

比较 id 时**先归一**：剥掉可选前缀（DSH 是 `session-`）、忽略大小写。
> 踩过：同一个会话在账本 `window` 字段带前缀、`caller` 字段不带 —— 直接比字符串会让
> **归属者被自己的目录拦住**，功能等于废。

三条都不命中 → 拦。`entry.label` 为空时不做子串匹配（空串会匹配一切）。
**读不到调用者标签时判为"不是归属者"**（更严，不会误放行）。

## 5. 拒绝文案

```
【已隔断】不得访问<什么>。
<可选：命中的参数名与原始值>
这是策略决定，不是临时故障，请勿重试或用其它方式绕过。<可选：范围提示>
```

`<什么>` 要**具体**，并且**按实际配的那一种归属说**：

| 情形 | 文案 |
|---|---|
| 会话记录 / 投影缓存 / 凭据 | 会话落盘记录（窗口 xxxx）／会话投影缓存（明文，含进行中的草稿）／宿主凭据文件 |
| 臂间隔离，只有 `label` | 自定义拦住目录（归属者：标签「臂B」，本调用的标签不匹配） |
| 臂间隔离，只有 `owner` | 自定义拦住目录（归属者：窗口 bbbb-2222…，本调用不是它） |
| 臂间隔离，都没设 | 自定义拦住目录（这条规则没设归属，对所有人拦住） |

> 踩过：纯标签规则被拒时提示却说"未指定归属窗口"，排查时被带偏。

## 6. 两条判定线：路径族必须精确，命令族只能是启发式

| | 怎么判 | 保证 |
|---|---|---|
| **路径族**（读/写/列目录/搜索类工具） | 把该工具**所有可能带路径的参数**都取出来逐个 `normalizePath` + 分类 | **精确**。必须覆盖所有参数 —— 只查 `path` 会被 `glob` 的 `pattern` 绕过去（实测踩过） |
| **命令族**（执行命令/脚本类工具） | 命令文本里是否出现敏感路径/关键字的**字面**模式 | **启发式**。拼接、变量、base64 可绕 —— 必须在文档里明说 |

命令族还要一条：**只在该类保护确实开着时才拦**，否则关掉凭据保护后，
普通命令仍会因为文本里出现会话路径而**误伤**。

## 7. 账本一条记录

JSON Lines，一行一条，**追加写**：

```json
{"ts":"2026-10-11T14:46:03.123Z","action":"deny","kind":"custom","tool":"read",
 "target":"C:\\…\\臂B\\只有臂B能看.txt","window":"session-2db5727b-…",
 "scope":"subagents","callerIsSubagent":true,
 "caller":"746f6448-c995-4446-b0a2-0b959f205c7c","mode":"all"}
```

| 字段 | 为什么必须有 |
|---|---|
| `ts` | 事后对齐时间段 |
| `kind` | 哪一类保护命中（`sessions`/`projcache`/`credentials`/`shell`/`custom`） |
| `tool` | 用的哪个工具 |
| `target` | 碰的什么（截断到合理长度） |
| `window` / `caller` | **判"谁干的"**：两者不同才有信息量（同窗口多个子代理 → window 相同、caller 不同） |
| `callerIsSubagent` | **身份判定是否生效**，没这一条事后无法判断记录怎么来的 |
| `scope` / `mode` | 当时的配置，否则事后无法复现判定 |

> **账本要能失败而不影响主流程**：写不进去也不能让工具调用崩（DSH 版是整段 try/catch）。
